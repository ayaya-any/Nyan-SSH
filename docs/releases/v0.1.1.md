### 外观与布局

- 新增窗口透明度设置，可在 55%–100% 之间调整并持久化。
- 新增本地背景图设置，支持选择、清除、自动等比裁切铺满和主题色遮罩。
- 左侧栏支持收起/展开：展开时按钮位于侧边栏顶部，收起后保留窄栏的展开、新建连接和设置入口，也支持 `Ctrl+B`。
- 标题栏不再显示侧边栏切换按钮。

### 会话与交互

- 新增会话独立窗口：可通过会话工具栏、标签右键菜单或 `Ctrl+Shift+P` 弹出；关闭独立窗口或点击返回按钮会把同一会话移回标签页，不中断连接。
- 保持会话标签、SFTP 文件面板和终端状态在弹出/返回过程中不变。

### 改进与修复

- 等宽字体下拉框改用 `QFontDatabase::isFixedPitch()` 精确筛选系统字体。
- 改进设置页数字输入框、标签栏绿点和关闭按钮的间距与对齐。
- Material 图标按实际墨迹边界渲染，修复部分图标偏移、截断和最大化/还原别名问题。
- 新增外观设置持久化测试，并更新界面截图与使用说明。

### 兼容性说明

- 设置文件保持向后兼容，原有主题、终端字体和会话配置会继续沿用。
- 支持 Windows 10/11 x64。
- 本次 GitHub Release 构建使用公共 aqt 仓库当前可用的 Qt 6.10.3；本地开发仍默认首选 Qt 6.12.0。
- 已知限制：私钥仅支持 PEM；不提供 keyboard-interactive/OTP；延迟为 TCP RTT 近似值。
